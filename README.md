# cafe-lp

Landing pages for a stylish cafe, generated from one prompt and archived here unmodified,
one directory per model.

```text
おしゃれなカフェのLPサイトを作って
```

(The prompt was given in Japanese: "Make a stylish cafe landing page.")

## Viewing

Published at <https://making.github.io/cafe-lp/>. The root `index.html` lists the works;
each entry links to its own page.

## Contents

| Model | Work | Description |
| --- | --- | --- |
| `GLM-5.3-Flash-FP4-Local` | [KOMOREBI CAFE](https://making.github.io/cafe-lp/GLM-5.3-Flash-FP4-Local/) | A landing page for "KOMOREBI CAFE" with concept, menu, store information and a reservation call to action. |
| `DeepSeek-V4.1-Flash-1017` | [KOKAGE COFFEE](https://making.github.io/cafe-lp/DeepSeek-V4.1-Flash-1017/) | A full landing page for "KOKAGE COFFEE" with concept, menu, gallery, access and reservation sections. |

## Running

Every page is a single self-contained `index.html` with no build step and no external
dependencies. Open the file you want to view directly in a browser; no server is needed.

## Notes

- Directory names identify the model that produced the page; no other metadata is attached.
- The code is preserved as generated. No shared stylesheet, framework, or cleanup was applied.
